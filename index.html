Questions

Is this allowed by Twitch?
Each transcribed stream plays in Twitch's official embedded player inside fever, so you count as a viewer and ads play; fever doesn't block ads, re-host video, or store anything server-side. You log in with Twitch's own device flow and chat as yourself.
How accurate is the transcript?
It uses the same Whisper model family as most live-captioning tools, running locally on Apple Silicon. Names come from voice matching, so collabs read like a script.
How long can I replay a line?
For as long as the app is open. Clips live in memory on your machine and are gone when you quit. Nothing is uploaded.
What about Windows?
Mac first because that's where the engine runs best. Windows and Linux follow, with a lighter model.
